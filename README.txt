Réflexofeet&co — site vitrine

## Aperçu
Ouvrez `index.html` dans un navigateur. Le site est responsive (ordinateur, tablette et téléphone).

## Personnalisation indispensable avant publication
1. L’adresse de contact est déjà configurée dans `script.js` : jessicaridelle@live.be.
2. Les coordonnées fournies sont intégrées. L’adresse personnelle complète n’est pas affichée : le site indique seulement « Cabinet à Winenne (5570) · sur réservation ».
3. Vérifiez les textes pour qu'ils correspondent exactement à vos pratiques et à votre cadre professionnel.
4. Ajoutez une politique de confidentialité si vous publiez le site et collectez des données personnelles. Le formulaire actuel prépare un e-mail via le logiciel de messagerie du visiteur ; il ne stocke ni n'envoie les données à un serveur.
5. Pour une prise de rendez-vous en ligne, connectez un outil de réservation ou un service avec backend. Aucun rendez-vous n'est confirmé par cette version.

## Publication
Le site est composé de fichiers statiques : `index.html`, `style.css` et `script.js`. Ils peuvent être publiés sur un hébergeur statique (par exemple GitHub Pages, Cloudflare Pages ou Netlify) après configuration du domaine et vérification des obligations légales applicables.
